# Clips

Screen recordings of the real app (release build, English) on a phone-sized
Android screen, 1080 × 2160, H.264 MP4, no sound. Each has a poster frame
(`*_poster.webp`) taken at the clip's key moment. Use them as muted loops
(`<video autoplay muted loop playsinline poster=…>`), ideally inside a phone
frame. Trim the first and last second if they show the app opening.

| Clip | Length | What happens | Good for |
|---|---|---|---|
| `tick_and_thread.mp4` | ~12 s | Two grocery items get ticked, then a thread is dragged from the voice note's pin to the recipe's pin ("Thread tied") | Hero, threads section |
| `drag_and_turn.mp4` | ~12 s | A note is picked up, moved, turned by its corner grip, and put back | "Move them like paper" |
| `tidy_up.mp4` | ~12 s | *Arrange → Tidy up*: every note flies into neat rows | Tidy up |
| `apply_theme.mp4` | ~16 s | *Templates & themes → Themes → Dark Chalk → Apply*: the wall, papers and fonts change in place, then Undo | Templates and themes |
| `switch_boards.mp4` | ~10 s | Home → Summer trip (memory wall) → Work (Kanban) → Home | Boards, memory walls |
| `draw_on_wall.mp4` | ~24 s | Marker mode on the chalkboard: a circle, a tick and a wavy line in chalk | Make it yours |
| `lights_off.mp4` | ~11 s | Lights off, then back on | Night mode |

The recordings run at the speed the emulator drew them; a few frames may
stutter. For a smoother loop, trim to the key moment and speed it up
slightly (1.25×). No Vietnamese clips were recorded; the Vietnamese page can
use these (the gestures read without words) or the Vietnamese stills.
