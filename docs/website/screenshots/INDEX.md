# Screenshots

Real captures of Sticky Wall 1.6.0 (release build) on an Android emulator,
with realistic sample data (an everyday home board, a trip memory wall with
real photos of Vietnam, a work board). Nothing is mocked up or retouched;
the status bar was set to a clean 9:41.

| Folder | Size | What |
|---|---|---|
| `phone/en/`, `phone/vi/` | 1080 × 2160 | Phone, portrait, English / Vietnamese |
| `desktop/en/`, `desktop/vi/` | 1920 × 1080 | Large screen, landscape (tablet / desktop window), English / Vietnamese |

All files are WebP (quality 90). The same file name exists in each folder,
except `07`: the phone has `07_editor_text`, the desktop has
`07_editor_text_formatting`.
